# GadgetStore бойынша 6 зертханалық жұмыс

Негізгі артефакттар:

- `GadgetStore_Lab6.ipynb` — орындалған код, гистограмма, кумулятивтік қисық, квантильдер, детерминистік салыстыру және покердің оқу хаттамасы.
- `GadgetStore_Lab6_Slide.pptx` — тапсырыс берушіге арналған бір өңделетін слайд.
- `monte_carlo.py` — notebook кодын Python файлы ретінде іске қосу нұсқасы.
- `lab6_results/` — графиктер, есептеу нәтижелері және кіріс/покер кестелері.

## Деректер мәртебесі

Throughput — 6-дәрістің 25-слайдындағы оқу мысалы: 3, 8, 4, 10, 2, 7, 9, 5, 6, 6.
Бұл GadgetStore трекерінің нақты тарихы емес. 60 элементтік бэклог 5-ЗЖ-ның 10 WBS пакетіне сәйкестендірілген оқу декомпозициясы.
55 SP, 11 SP/спринт velocity және покердің A/B/C дауыстары — оқу сценарийі.
Нақты адамдар қатысқан покер сессиясы өтті деп көрсетілмейді.

## Қайта іске қосу

Google Colab-қа `.ipynb` файлын жүктеп, Runtime → Restart session and run all таңдаңыз.
Notebook ішінде барлық кіріс деректер бар. Интернет арқылы API дерегі алынбайды.

Жергілікті Python 3.12 ортасында:

```powershell
python -m pip install -r requirements.txt
python monte_carlo.py
```

Нәтижелер `lab6_results` папкасында қайта жасалады. Seed = 20261008, жүгірту саны = 10 000.
Графиктің мазмұны қайталанады, шрифт көрінісі операциялық жүйеге қарай аздап өзгеруі мүмкін.

## Нәтиже

P50 = 10, P70 = 11, P85 = 12, P95 = 13 белсенді апта.
Қарапайым 10 апталық мерзімге модель жүгіртулерінің 53,01%-ы аяқталады.
Күнтізбелік есепте басталу 12.10.2026, оқу үзілістері 4 және 12-апта деп алынған.
P85 күні — 17.01.2027. Бұл нақты жобаға берілген уәде емес, оқу моделінің шартты нәтижесі.

## Тапсыру алдында

Notebook-та аты-жөніңіз бен тобыңызды жазыңыз. Оқытушы нақты командалық сессияны талап етсе,
покер бөлімін шын қатысушылардың дауыстарымен толықтырыңыз. Нақты throughput пен velocity берілсе,
кіріс ұяшығын өзгертіп, notebook-ты қайта орындаңыз және слайдтағы күндерді жаңартыңыз.
